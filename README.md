# Java Streams Exercises

Учебный проект с решениями 9 задач на Java Stream API.

## Требования
- JDK 17 или новее
- Maven (или запуск класса напрямую из IDE)

## Запуск
Откройте папку проекта в IntelliJ IDEA как Maven-проект и запустите `Main.java`.

Из командной строки из корня проекта:
```bash
mvn compile
java -cp target/classes com.example.streams.Main
```

## Структура
- `Main.java` — запускает все упражнения и печатает результаты.
- `StreamExercises.java` — решения задач 1–9.
- `Employee.java` — модель сотрудника.

Для упражнения 2 повторяющиеся числа считаются отдельно. Для упражнения 3 числа сначала делаются уникальными.
